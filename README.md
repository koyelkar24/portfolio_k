# Koyel Kar — Portfolio

A personal portfolio website built with HTML, CSS, and JavaScript.

## Run locally

From this folder, start a local web server:

```powershell
py -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. Press `Ctrl+C` in the terminal to stop the server.

## Files

- `index.html` — page content and structure
- `style.css` — layout, visual styles, and responsive design
- `script.js` — navigation and page animations
- `kar.jpeg` — portrait image
- `Koyel_Kar_Resume_Improved.pdf` — downloadable resume
